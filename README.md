# Sesión 11 · Tracks con Supabase

Repositorio de arranque del taller de la sesión 11 del Seminario de Ingeniería de
Software.

```shell
flutter pub get
flutter run -d chrome
```

La app ya crea, muestra y elimina tracks, pero solo en memoria: al recargar se
pierden. En el taller los guardas en la tabla `tracks` de Supabase llenando
`lib/services/track_services.dart`.
